# Name Origin

Anula is based on the lands of Adal. Daklyn spent most of his time on DeMoch, but did go to Adal for quite some time. The name "Adal" literally means "The Island", and Daklyn probably thought naming a continent based on that was a little inaccurate or on the nose. Instead, he used a name the Kithral Lle used for the place, 'ajangshula Rungdo' which literally translates to 'Land across the strait' This was shortened quite significantly to 'Anula', using only the first part of the word (which means "the strait"). An alternative name for Anula would be Anularo, using the second part of hte name as well.
